Meet Sparky!

The official robot mascot of the Curiosa Science Museum. Sparky loves experiments, discoveries, and welcoming curious minds of all ages.

Happy and ready to explore!

Add Sparky to any page

Copy sparky-mascot.html into your project and link to it, or paste the <figure> block and the <style> directly into any page. Sparky uses pure CSS animations — no JavaScript frameworks, no external libraries. Call sparkySetMood('excited') from any page script to trigger a mood.
